# LEVEL UP — Android PWA

## Что внутри
- Тёмный интерфейс на русском языке.
- Квесты и начисление XP.
- Уровни персонажа и категории навыков.
- Достижения и недельный отчёт.
- Локальное сохранение в браузере.
- Экспорт и импорт резервной копии JSON.
- Service Worker для офлайн-работы после первой загрузки.

## Как открыть на Android
PWA требует HTTPS (или localhost). Самый простой путь:
1. Распаковать архив.
2. Разместить все файлы на HTTPS-хостинге, например GitHub Pages.
3. Открыть ссылку в Chrome на Android.
4. Нажать меню Chrome → «Установить приложение» или «Добавить на главный экран».

Можно также сначала открыть `index.html` локально для проверки интерфейса, но установка PWA и офлайн-кэш могут не работать через `file://`.

## Сохранение
Данные хранятся в localStorage браузера на этом устройстве. Очистка данных браузера может удалить прогресс. Регулярно используйте «Настройки → Экспорт данных».

## Примечание
Это первая версия. Квесты повторяются ежедневно; завершение каждого квеста даёт XP один раз за календарный день. Для пользовательских квестов действует то же правило.
